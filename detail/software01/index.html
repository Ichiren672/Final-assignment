概要

MinecraftサーバーにBungeeCordでプロキシサーバーを構築しているあなたへ！
別ワールドへの移動を看板右クリックで可能にします。

このように、ワールド名とそのワールドの接続人数がリアルタイムで更新されます！
詳しくは「使い方」タブを確認ください。

動作環境

動作環境のテスターを募集しています！
動作環境外でも利用していただき、動作結果と環境をお伝えしていただけるとありがたいです！

このソフト自体はLAN外通信を使用していません。

確認・報告済み動作

  • サーバーOS :
    Windows 10 64bit~
    Ubuntu server 22.04~
  • 実行ソフト :
    Java 21~
  • ゲームソフト(クライアント) :
    Minecraft Java Edition
  • ソフト(Minecraftサーバー側) :
    PaperMC 1.21~
  • ソフト(Minecraftプロキシ側) :
    BungeeCord(サーバー側に合わせたもの)

インストール手順

当サイトDLタブから.jarファイルをダウンロードします。
ダウンロードデータの確認用にSHA-512のハッシュ値を記載してあります。正当性の確認のためにご利用ください。

PaperMCの場合

このソフトを利用したいワールドの起動ディレクトリに移動してください。
paperMCのjarファイルのカレントディレクトリに/pluginディレクトリがあります。
そちらにダウンロードしたjarファイルを入れてください。
paperMCサーバー起動時に次のログが出力されれば起動できています。

plain text
Bungeemove plugin by K.Yusuke

利用方法

移動看板を作成する

プラグインを入れたMinecraftワールドでのみ利用可能です。
看板にのみ適用されます。
看板に次のコマンドを入れて確定をすると、看板の表記が切り替わり有効となります。

plain text
[BungeeMove] 移動先ワールド名 (入力不要) (入力不要)

また、入力できない小さい看板に追加するときは、dataコマンドを使って直接入力してください。
看板を確定するのを忘れないでください(上の2つ目の動画参照)
コマンドに詳しくない方のために、実行コマンドを貼っておきます。

plain text
/data merge block ~ ~ ~ {front_text:{messages:["[BungeeMove]","worldName","",""]}} 看板の座標に立って実行すること

一度作成すると、jsonファイルに情報が保存されます。
そのため、サーバーを再起動しても正常に動作します。

移動看板を削除する

作成した看板を右クリックで壊すと自動で削除されます。

サーバー名について

ワールド名は、BungeeCordで設定されている名前にしてください。
BungeeCord内のconfig.ymlで確認してください。

推奨

このプラグインを導入したワールドはアドベンチャーモードを推奨します。
どの権限・ゲームモードでも右クリックで作成や削除ができるためです。
